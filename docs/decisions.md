# 业务决定记录

对应任务清单第 01–07 项。每项填写明确答案后，再实现依赖它的功能。

- 决定日期：2026-10-11

## D-01 价格口径

- 地区与币种：中国大陆官方渠道（范围见 D-08），人民币（CNY）。
- 税费：按官网展示的价格，不另外计算税费。
- 可以算作“官方参考价”的价格类型：
  - 官网当前标价，且对应推荐的具体配置（`list_price`）。
  - 起售价，仅当推荐的配置恰好就是起售配置时才算（`starting_price`）。
  - 上市参考价或官方公告价（`launch_price`），仅在在售页面查不到时使用，并注明公告日期。
  - 官方促销价（`promotion`），需同时记录促销条件。
- 不算作官方参考价：教育优惠价、以旧换新后的价格、分期月供。
- 不同价格类型之间不直接计算差价，比较时标为“不可直接比较”。

## D-02 缺价与候选不足策略

- 配置已核实、但查不到官方价时：直接保留，标注“未查到官方价”，价格比较中写“无法比较”。
- 核实后有效候选不足三款时：有几款给几款，并说明不足的原因；不虚构候选。
- 每个候选第一次没查到资料时，最多补查 1 次。

## D-03 候选范围规则

- 同一型号的不同配置不能各占一个推荐名额；每个型号最多占一个名额，配置差异写进理由。
- 联网检索时新发现、AI 最初没有提出的型号可以加入候选，但必须经过同样的核验，并标注来源为“检索中发现”。

## D-04 信息缺失与需求冲突的处理

- 必要信息：由 AI 为五个品类分别起草清单，用户审阅确认（已确认，见下表）。
- 必要信息未知时最多追问 1 轮。追问后仍然未知的，按未知继续推荐，并在结果中说明这项信息会怎样影响选择；不替用户假设。
- 需求冲突时：在这 1 轮追问内让用户澄清；追问用完仍有冲突，就在结果中分别说明不同的取舍。

## D-05 数据留存范围

- 用户输入（选项和原话）：服务器不保存，请求结束就丢弃。
- 诊断日志：不记日志。
- 缓存：缓存网页读取结果 24 小时。只缓存公开官网页面的读取结果，不缓存用户输入、模型输出或推荐结果；缓存只放在后端进程内存里，重启即清空；结果中展示的访问时间为页面实际读取的时间。
- 不记日志的具体含义：不写日志文件。每次推荐只在运行后端的终端里打印一行耗时与调用量汇总（任务 46），不包含用户原话，用来核对单次费用。
- App 关闭后，没提交的编辑内容不保留。

## D-06 模型供应商

- 每次推荐的费用上限（模型加搜索）：不超过 1 元人民币。
- 可以接受的等待时长：不超过 120 秒。
- 数据保留设置：接入时核对 DeepSeek 的数据使用与保留条款后补记。

## D-07 联网接法与搜索供应商

- 联网方式：方案 A，独立搜索 API 加程序自行读取网页。
- 搜索供应商：阿里云 CleverSee（原信息查询服务 IQS），接口为 `POST https://cloud-iqs.aliyuncs.com/search/unified`。
- 调研时的价格（2026-10）：标准版（Generic）每千次 42 元，极速版（CNLiteBasic）每千次 12 元；新用户有体验额度，测试期每天限 1000 次。
- 引擎版本：极速版（`CNLiteBasic`）。接口文档写明只有这个版本支持 `includeSites`，而 D-08 的查找顺序需要按渠道限定站点。
- 每次搜索返回 10 条结果（`numResults=10`）。按次计费，条数不影响费用。
- 返回内容只用标题、链接、摘要（摘要只用来定位）和发布时间；正文副本（`mainText`、`markdownText`、`richMainBody`）和增强摘要（`summary`）都关闭，因为它们不是本次实际读取的页面。
- 详细的请求参数、搜索词写法、补查和错误处理见 `docs/CleverSee查询规范.md`（草案，部分内容待任务 24 实测）。程序仍会按官方渠道规则（任务 23）再过滤一遍搜索结果。
- API Key：**待取得**（CleverSee 控制台 → API Key → 创建），取得后保存到 `backend/.env`。

## D-08 官方渠道范围与查找顺序

- 决定日期：2026-10-11
- 官方渠道以 `outputs/中国电商官方渠道汇总.md` 为准，包括品牌官网、品牌官方商城、品牌在京东和天猫的官方旗舰店。程序使用的规则表为 `backend/app/config/official_channels.json`。
- 只收录清单中“已验证”的渠道；“待验证”和“渠道说明页”不作为参数或价格来源。
- 查找参数页和价格时的优先顺序：
  1. 品牌官网与官方商城；
  2. 京东官方旗舰店；
  3. 天猫官方旗舰店。
- 京东、天猫的商品详情页（如 `item.jd.com/数字.html`、`detail.tmall.com/item.htm?id=…`）不在店铺自己的域名下，必须在页面中找到指向该品牌官方旗舰店的链接，才算官方渠道页面。
- 本决定扩大了 D-01 中“官网”的范围；地区（中国大陆）、币种（人民币）和允许的价格类型不变。
- 京东、天猫商品页上的价格：只有页面标价（如“京东价”）算官方参考价；券后到手价、国家补贴价、PLUS 会员价等需要满足条件的价格都不算，和教育价、以旧换新价的处理一致。
- 三款候选的价格来自不同渠道时（例如一款是官网价，另一款是京东官方旗舰店价），可以直接比较差价，但每个价格旁边要标明来源渠道。
- 规则表严格以渠道清单为准，不额外收录清单之外的地址（如 samsung.com/cn、sony.com.cn、microsoft.com/zh-cn、opposhop.cn 的一加专区）。
