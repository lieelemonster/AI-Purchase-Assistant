## 人为错误

太平洋产品库不使用搜索密钥。下面用“搜索直接失败”代替“密钥写错”和“断网”：搜索步骤报错后，不再继续读页面。

| 设置 | 状态 | 是否被报成成功 |
| --- | --- | --- |
| 整次时限 0.05 秒 | timeout | 否 |
| 搜索次数上限 1 | insufficient_candidates | 否 |
| 搜索直接失败 | insufficient_candidates | 否 |

这三种都在时限内结束，并给出了明确状态。
