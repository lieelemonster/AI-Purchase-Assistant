# 购买选择助手 · UI 规格说明（供 AI / 开发阅读）

> 本文件完整描述当前原型的所有页面、状态、组件、设计变量与交互流程。目标平台：iPhone + Android，后续使用 Flutter 开发。
> 所有产品、参数、价格均为**设计演示数据**，不代表真实核实报价。
> 参考实现源码：`src/App.tsx`（页面与流程）、`src/ui.tsx`（组件）、`src/data.ts`（数据与题目配置）、`src/Spec.tsx`（规范页）、`src/index.css`（设计变量）。

---

## 1. 产品定位

帮助"想买某类商品，但不清楚自己需求、也不了解产品区别"的普通用户，通过选项辅助与自由补充梳理需求，最终做出购买选择。辅助决策工具，**不是电商商城**。

第一版品类：笔记本、手机、平板、显示器、耳机。原型以「笔记本」演示完整流程（其他品类入口目前也进入笔记本题目）。

核心流程：
```
01 选择品类 → 02 需求梳理(3题) → 03 需求确认 → 04 查询核实 → 05 推荐结果 → 06 产品详情 / 07 三款对比
```

### 首版不做
登录注册、账号中心、购物车/下单/支付/购买跳转、跨店比价、优惠券、降价提醒、收藏、历史记录、社区评论分享、后台管理。不放过多提示语。

## 4. 页面详述

### 01｜选择品类（home）
- 无 TopBar，无底部按钮。
- 内容（上边距 56，左右 24）：
  - 标题（Display，两行）："想买什么？" / "我们一起理清楚。"
  - 辅助说明（16，ink-2）："还没想清楚需求也没关系。"
  - 间距 48 后，五个品类入口，**单列纵向列表**，间距 12：
    | 品类 | 说明 | 图标底色 |
    |---|---|---|
    | 笔记本 | 办公、学习、创作 | primary-soft |
    | 手机 | 拍照、续航、日常 | mint |
    | 平板 | 看剧、记笔记、绘画 | lilac |
    | 显示器 | 办公、游戏、设计 | warn-soft |
    | 耳机 | 通勤、运动、降噪 | err-soft |
  - 每行：48×48 圆角图标块 + 名称(17/600) + 说明(13/ink-3) + 右箭头。白卡、1px 边框、圆角 16。
- 交互：点击任一品类 → 02 需求梳理第 1 题。
- 不设商品瀑布流、促销横幅、排行榜、登录门槛、搜索入口。

### 02｜需求梳理（ask）
- TopBar：左返回（第 1 题返回首页，否则回上一题）；中间为"品类图标 + 品类名"。
- **无进度条**，不显示固定题数。
- 每次只聚焦一个问题：
  - 问题标题（Title 22）
  - 标签行：多选题显示「✓ 可多选」（primary 标签）；单选题显示「单选」（灰标签）；可附一行 helper 说明。
  - 选项列表（OptionItem，间距 10）
  - **自由补充输入框仅在第 1 题出现**：标题"你的想法都可以告诉我"（无句号），占位符"比如：想学 AI 产品经理、宿舍没有桌子、喜欢银色…"，最多 200 字，显示字数。
- 底部：第 2 题起左侧「上一题」(次按钮, 宽 112) + 右侧主按钮。主按钮无选择时文案「先跳过」，有选择时「下一步」；最后一题点击进入 03。
- 选择规则：单选题点选即替换；多选题可多选；选择"不确定类"选项会清空其他选项，选择其他选项会取消"不确定类"选项。
- 题目配置（可由后端下发，可按品类替换）：

| # | 标题 | 类型 | helper | 选项 |
|---|---|---|---|---|
| 1 | 你现在为什么想买一台电脑？ | 多选 | 说说你会用它做什么，选你最接近的情况就行。 | 日常办公（文档、表格、开会）/ 学习（上网课、查资料、写作业）/ 经常携带（通勤、出差、去图书馆）/ 剪视频或修图 / 玩游戏 / 还不清楚(不确定类) |
| 2 | 你大概愿意花多少钱？ | 单选 | 无 | 4000 元以内 / 4000–6000 元 / 6000–8000 元 / 8000 元以上 / 还没想好(不确定类) |
| 3 | 以下这些你更在意什么？ | 多选 | 无 | 轻一点，好带 / 续航久，少充电 / 屏幕看着舒服 / 多开软件不卡 / 安静、不烫手 / 不确定(不确定类) |

- 状态：已选中、未选中、不确定类（虚线边框）、输入框默认、输入中（蓝色描边+外发光，底部显示"输入中…"）、键盘弹出。
- 不要求用户理解 CPU、显存、色域等术语。

### 03｜需求确认（confirm）
- TopBar：左返回（回 02），标题"确认需求"。
- 标题："这是我目前理解的需求"；说明："有不对的地方，点"修改"就能调整。"
- 分区「✓ 已明确」（白卡，行之间分割线），每行：小标签 + 蓝色胶囊值 + 右侧「✎ 修改」：
  - 主要用途：第 1 题所选（不含"还不清楚"）
  - 预算：第 2 题所选
  - 偏好：第 3 题所选
  - 限制：无其他限制
  - 未回答的项目不在此显示，**不自动填入假设**
  - 「修改」跳回对应题目
- 分区「✎ 你的想法」：只显示第 1 题输入框里用户填写的原文；未填写显示"未填写"（ink-3）；右侧「修改」跳回第 1 题。
- 不从"学习 AI"推断需要本地训练模型或高性能显卡。
- 底部主按钮（带搜索图标）：「开始寻找符合你的产品」→ 04。

### 04｜资料查询与核实（search）
- TopBar：左返回（回 03）。
- 标题："正在查找适合你的产品"
- 阶段卡片（四行，每行：圆形状态图标 + 阶段名 + 右侧状态文字）：
  1. 整理需求 2. 查找候选产品 3. 核对配置与价格 4. 整理推荐理由
  - 状态：已完成（绿底✓）/ 进行中（蓝底旋转图标）/ 等待中（灰点）/ 未完成或部分失败（橙底⚠）
- 骨架屏卡片（3 条脉冲灰条）。
- 提示（ⓘ）："会尽量核对具体配置，避免把不同版本混在一起。"
- 底部：「返回修改需求」（次按钮）。
- 约每 1.1 秒推进一个阶段，完成后自动进入 05。**不显示百分比或倒计时。**
- 异常状态（标题区替换为橙色圆形图标 + 标题 + 说明）：
  | 状态 | 标题 | 说明 | 底部按钮 |
  |---|---|---|---|
  | 查询超时 | 查询时间比预期长 | 资料来源响应较慢，你填写的需求都已保留。 | 修改需求 / 重试 |
  | 部分资料读取失败 | 部分资料没能读取 | 有 1 款候选的价格页面读取失败。可以重试，或先看已核实的结果。 | 先看已核实的 / 重试 |
  | 网络请求失败 | 网络连接失败 | 请检查网络后重试，你填写的需求都已保留。 | 修改需求 / 重试 |

### 05｜推荐结果（result）
- **结果出来后不允许修改需求，也不能返回需求页面。**
- TopBar：无返回按钮；标题"推荐结果"；右侧「⌂ 首页」按钮 → 01。
- 需求摘要（NeedSummary，只读胶囊，无修改入口）：用户想法 + 用途 + 预算（未选显示"预算未定"）+ 偏好，最多 5 个。
- 标题："根据你的需求，优先考虑这款"
- 首选卡片（2px 主色描边）：
  - 顶部条（primary-soft）：「✓ 首选」+ 右侧「设计演示数据」虚线标签
  - 品牌（13 ink-3）/ 完整型号（19/700）/ 具体配置（14 ink-2）
  - 价格（24/700）+「参考价」标签
  - 一句话推荐理由（16/500）
  - 「✓ 符合你的需求」（绿）：理由卡 ×2，结构为 **你的需求 → 依据 → 对你的影响**
  - 「⚠ 需要接受的取舍」（橙）：列表
  - 「查看详细理由」次按钮 → 06
- 「备选」分区，每张卡：品牌、型号、配置、（如有）「⚠ 具体版本待核实」、价格 +「参考价」、灰底框"什么情况下更适合：…"、右箭头，整卡可点 → 06。
- 底部主按钮：「三款对比」（不足三款时为「N 款对比」）→ 07。
- 不展示匹配分数、销量、评价、"全网最优"等无依据结论。
- 状态：
  - 正常：首选 + 2 款备选
  - 核实不足三款：按实际数量显示（如首选 + 1 款备选），标题旁"（核实到 1 款）"，右侧"只展示资料核实过的产品"
  - 没有找到产品：需求摘要 + 居中空状态图标 + 标题"没有找到符合条件的产品" + 说明（解释哪些条件组合未核实到型号）；底部主按钮「重新开始」→ 01

### 06｜产品详情与推荐依据（detail）
- TopBar：左返回（回 05），标题"推荐依据"，右侧「设计演示数据」。
- 品牌 · 首选/备选；完整型号（22/700）；配置；如有「⚠ 具体版本待核实」。
- 价格卡：价格 +「参考价」；说明"价格为参考，不同口径的价格不能直接比较。"
- 「✓ 为什么适合你」：理由卡（需求 → 依据 → 影响），逐条对应用户选择与自由补充。
- 「⚠ 需要权衡什么」：橙色浅底卡，"不足" + "影响：…"
- 「ⓘ 关键参数」：白卡列表，默认只显示与需求相关参数（标「与你相关」），底部「展开其他参数 / 收起」。缺失值显示「? 暂无核实资料」；冲突值附「⚠ 资料存在冲突」+ 说明。
- 「资料来源」：每条显示来源名称、页面链接、查询时间、来源更新时间（两者分开）；底注"链接仅用于查看资料证据。"**不提供购买链接。**

### 07｜三款对比（compare）
- TopBar：左返回（回 05），标题"三款对比"/"N 款对比"，右侧「设计演示数据」。
- 顶部三列产品头卡：标签（首选 A / 备选 B / 备选 C）、型号、价格（区间显示"¥X起"，缺失显示"暂未查到"）、下方"参考价"。首选为主色描边浅蓝底；未核实到的列置灰。
- 橙色提示条："三款价格口径不同（参考报价、官方价、区间），仅作大致参考。"
- 「按你关心的方面」+ 右侧「只看差异」开关（默认开）。
- 对比行（CompareRow）列表，每行：维度名 + 三列值（首选列浅蓝底）+ 一句易懂解释。缺失值显示"暂无资料"。
- 底部「怎么选」卡片：
  - A：如果你更在意每天携带和续航，优先考虑 A。
  - B：如果你愿意接受更重一些，想要更大屏幕，可以考虑 B。
  - C：如果预算更紧，并愿意先核实内存版本，可以考虑 C。
- 采用"按维度分行、每行三格"的纵向布局，避免横向表格挤压文字。
- 不同品类使用不同对比维度：
  | 品类 | 维度 |
  |---|---|
  | 笔记本 | 重量、屏幕、续航、内存、接口（显卡） |
  | 手机 | 拍照、续航、屏幕尺寸、重量、存储 |
  | 平板 | 屏幕、手写笔支持、存储、重量 |
  | 显示器 | 尺寸、清晰度、刷新率、接口、支架 |
  | 耳机 | 佩戴方式、降噪、续航、通话、重量 |

## 7. 价格与来源规则

- 所有价格旁一律显示「参考价」标签（缺失价格除外）。
- 数据层仍保留价格类型以便后续区分：太平洋参考报价 / 品牌官方价格 / 官方发布价 / 暂未核实价格；不能把太平洋报价标为品牌官方价格。
- 主要资料来源：太平洋科技。
- "查询时间"与"来源更新时间"分开展示。
- 价格缺失 → "暂未查到价格"；价格区间 → 明确标注区间；配置不明确 → "具体版本待核实"；参数缺失 → "暂无核实资料"；资料冲突 → "资料存在冲突"。
- 网络失败 → 保留用户已填内容并提供重试。
